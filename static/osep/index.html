教材簡介

SmartRingController 是一套結合 ESP8266、WebSerial、OSEP Scratch Editor 與 WS2812 LED 燈環的互動控制教材。 學生可以透過實體控制器操作 Scratch 角色，並控制 LED 燈環產生即時回饋。

本教材以「動手實作 → 統整反思 → 舉一反三 → 學習遷移」為核心， 從基礎互動控制逐步延伸到條件判斷、陣列應用與模組化程式設計。
