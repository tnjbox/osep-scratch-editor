# OSEP 第 5 章進階任務教材規劃

## 一、第 5 章定位

第 5 章是「進階互動控制」的延伸學習階段，承接第 4 章的基礎按鍵與角色操作。學生在前一章已了解基本的按鍵偵測、角色移動與簡單回饋後，將進一步學習如何讓角色在按住按鍵時持續移動、用變數控制速度、利用 LED 顯示程式狀態、透過條件判斷建立互動規則，以及整合分數、生命值與過關機制。

透過本章內容，教師可以協助學生從「單次操作」進入「持續控制」與「狀態反應」，逐步建立更完整的互動式程式設計思維。第 5 章的任務設計強調：一方面讓學生理解程式邏輯，另一方面讓學生看到硬體與角色行為之間的關聯。

## 三、C501｜連續按鍵控制

### 1. 教學目標
- 讓學生理解「按一下」與「按住」的差異。
- 讓學生知道如何使用重複無限次持續偵測按鍵狀態。
- 讓學生學會以 x / y 座標控制角色移動。
- 讓學生初步理解程式執行的持續性與角色動畫效果。

### 2. 教師示範題
- 使用 BTN1、BTN2、BTN3、BTN4 控制角色上下左右移動。
- 讓角色在按住按鍵時不斷移動，而不是只移動一次。
- 示範如何避免角色跑出舞台邊界。
- 可加入簡單的速度調整示範，讓學生理解後續任務的延伸方向。

### 3. 學生仿作練習
- 讓角色在按住上鍵時向上移動，按住下鍵時向下移動。
- 設計角色在左右鍵按住時沿 x 軸連續移動。
- 讓角色在碰到邊界時自動反彈或停止。
- 觀察按一下與按住時的角色表現差異。

### 4. 延伸挑戰
- 將移動步幅改為可調整的 speed 變數。
- 讓角色在不同按鍵組合下有不同移動效果。
- 加入簡易的「連續移動」與「單次跳躍」兩種模式切換。

### 5. 使用積木
- 重複無限次
- 如果
- 如果……否則
- x 座標
- y 座標
- 變數（例如 speed）
- 事件積木（例如點擊綠旗）

### 6. 自我檢核重點
- 是否有持續偵測按鍵的重複結構？
- 是否能在按住按鍵時連續移動？
- 是否有使用座標控制角色位置？
- 是否有避免角色移出舞台邊界的考量？
- 是否能清楚說明「按一下」與「按住」的差異？

### 7. Scratch 任務檔修改方向
- 可先從角色移動程式開始調整。
- 將原本單次移動積木改為重複偵測結構。
- 使用 BTN1～BTN4 判斷方向，並配合 x / y 座標更新角色位置。
- 將移動步數整理成可讀性較高的變數或常數設定。

## 四、C502｜速度與方向控制

### 教學重點
- 建立 speed 變數，用來控制角色移動速度。
- 讓學生理解速度與方向是兩個不同但相關的控制參數。
- 透過不同速度模式，讓學生比較慢速、中速、快速的效果差異。
- 可設計按鍵切換速度模式，讓互動更有層次。

### 建議學習流程
1. 建立 speed 變數並設定初始值。
2. 讓角色依照方向鍵改變 x / y 座標。
3. 使用 speed 決定每次移動的距離。
4. 加入 LED 顏色或提示，讓學生看見速度改變的效果。

## 五、C503｜LED 狀態提示

### 教學重點
- LED 不應只表示「按鍵被按下」，而要反映程式狀態。
- 讓學生看到角色狀態與硬體回饋之間的關係。
- 可依照角色移動、加速、碰邊界、完成任務等情況切換不同 LED 顏色。

### 建議學習流程
1. 先建立角色狀態變數，例如 mode 或 state。
2. 依照情境設定不同 LED 顏色。
3. 讓學生觀察同一個按鍵操作，在不同狀態下的回饋差異。
4. 將 LED 顏色與任務結果對應，提升學生對系統回饋的理解。

## 六、C504｜條件判斷互動

### 教學重點
- 使用 if 與 if-else 建立簡單的分支邏輯。
- 介紹角色碰到目標物時得分、碰到障礙時失敗或扣分的概念。
- 透過條件判斷讓程式產生不同結果。
- 加入成功與失敗 LED 回饋，讓學生看到條件判斷的實際效果。

### 建議學習流程
1. 設定目標物與障礙物。
2. 使用碰撞偵測判斷角色是否碰到目標或障礙。
3. 加入不同的得分或扣分規則。
4. 讓 LED 根據判斷結果顯示成功或失敗訊號。

## 七、C505｜分數與生命值

### 教學重點
- 建立 score 與 life 變數，理解遊戲資料的存取方式。
- 讓學生理解碰到寶物可增加分數，碰到障礙可減少生命值。
- 透過得分與生命值管理，讓學生體驗「遊戲目標」與「失敗條件」的設計。
- 可將分數或生命值以 LED 方式顯示，增加硬體互動感。

### 建議學習流程
1. 建立 score 與 life 變數。
2. 設計寶物碰撞與障礙碰撞事件。
3. 在分數達標時顯示過關畫面或切換下一階段。
4. 在 life 歸零時停止遊戲並顯示失敗結果。

## 八、C506｜進階挑戰任務

### 教學重點
- 讓學生整合 C501～C505 的核心概念。
- 鼓勵學生自行設計 SmartRing 互動作品，而非只重複教師範例。
- 至少包含方向控制、變數、條件判斷、LED 回饋與過關或失敗條件。
- 作品主題可依學生興趣選擇，例如迷宮逃脫、接寶物、閃避障礙、任務闖關或節奏反應。

### 建議學習流程
1. 由學生選擇主題與任務目標。
2. 教師協助學生整理需要的角色、物件與變數。
3. 學生依照任務需求設計流程與判斷條件。
4. 最後進行作品展示與同儕回饋。
